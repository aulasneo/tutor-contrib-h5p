# Changelog

All notable changes to this project will be documented in this file.

## Version 21.0.0 (2026-04-27)

### Added

- Initial release of `tutor-contrib-h5p`.
- Integration of the `h5pxblock` XBlock into Tutor-based Open edX deployments.
- S3-aware H5P media URL rewriting through the LMS host to avoid CORS and CSRF embedding issues.
- Support for both virtual-hosted and path-style S3 URL formats.
